Project FrontierGuard

FrontierGuard

FrontierGuard is a Windows PE protector designed to enhance the runtime security of executable files targeting the Windows x64 architecture through a multi-layered protection structure. It operates alongside the protected application at runtime, applying practical security techniques to help defend against reverse engineering, code analysis, and unauthorized modification.

About FrontierGuard

Aim

FrontierGuard provides runtime-focused memory protection for Windows applications against reverse engineering (debuggers, virtual machines), malicious memory operations (injecting, hijacking, dumping), and runtime manipulation.

Approach

FrontierGuard adopts a multi-layered, real-time protection architecture to significantly increase the cost and complexity of reverse engineering through a combination of obfuscation, runtime guards, and other advanced techniques.

Scope

The scope of this project is limited to usermode Windows PE files. Kernel components, firmwares, drivers, non-PE formats (Linux/macOS), and attacks originating from higher privileges (kernel driver, hypervisor, etc.) are explicitly out of scope.

Features

Startup Guards

Pre-Execution guards are designed to protect the applicaton before it is executed, preventing early analysis and tampering attempts. Few of these guards will enable stronger protections upon detection of analysis attempts.

Anti-VM

Detects virtual environments and enables event guards in case of analysis attempts.

ProxyGuard

Detects and responds to unauthorized static IAT hooking and DLL proxying attempts.

ExitGuard

Ensures the protected process can be safely terminated on a critical situation.

Runtime Guards

Runtime guards are designed to protect the application during execution, preventing runtime analysis and tampering attempts.

DebugGuard

Detects and responds to unauthorized debugger attachment and breakpoints attempts.

ThreadGuard

Detects and responds to unauthorized thread creation, suspension, and manipulation attempts.

LibGuard

Detects and responds to unauthorized runtime DLL injection, unloading, and stomping attempts.

ProcessGuard

Detects and responds to unauthorized child process creation attempts.

IntegrityGuard

Detects and responds to unauthorized dynamic memory modifications and code tampering attempts.

APCGuard

Detects and responds to unauthorized APC (Asynchronous Procedure Call) injection and manipulation attempts.

Event Guards

EventGuards are designed to protect the application by "responding" to security-sensitive events.
This will not prevent the events from occurring, but will instead respond to neutralize the attack or terminate the protected process.

ExploitGuard

Detects and responds to unauthorized network connection, memory corruption, and code execution attempts.
  1. Neutralizes the exploit by terminating the memory region.
  2. Terminates the protected process upon failure to neutralize the exploit.

MemoryGuard

Detects and responds to unauthorized memory operations that bypassed the runtime guards.
  1. Neutralizes the unauthorized memory operation by terminating the memory region.
  2. Terminates the protected process upon failure to neutralize the child process.

HeartbeatGuard

Manages the health of the guards and recovers upon failure to maintain the protections.
  1. Recovers the protections and restores the original state.
  2. Terminates the protected process upon failure to recover the protections.

Prevention Guards

Prevention guards are designed to completely disable or prevent additional operations to protect the application.
This is a more aggressive approach to security, as it limits the functionality of the protected process (disabled by default).

NetworkGuard

Disable all network operations for the protected process when enabled.

FileGuard

Detects and responds to unauthorized access or modification of files associated with the protected process.

ACGuard

Enables ACG (Arbitrary Code Guard) policy for the protected process.
